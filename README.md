# Hi, ich bin Baris

Ich befinde mich aktuell in der Umschulung zum **Fachinformatiker für Anwendungsentwicklung** und entwickle mich Schritt für Schritt in Richtung professioneller Softwareentwicklung. Mein Fokus liegt auf praxisnahen Projekten, sauberer Struktur, verständlicher Dokumentation und dem Aufbau belastbarer technischer Grundlagen.

Besonders interessieren mich Anwendungen, bei denen Software nicht nur theoretisch funktioniert, sondern reale Abläufe steuert, überwacht oder verbessert. Dazu gehören Python-Projekte, Automatisierung, Raspberry-Pi-Systeme, Schnittstellen, Sensorik, Datenverarbeitung und einfache, nachvollziehbare Systemarchitekturen.

## Was mich ausmacht

Ich lerne am besten über Logik, Zusammenhänge und praktische Anwendung. Deshalb arbeite ich gerne an Projekten, bei denen man ein Problem analysiert, eine saubere Struktur entwickelt und die Lösung anschließend Schritt für Schritt testet.
